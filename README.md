# jldlab.github.io

Racine du domaine GitHub Pages. Sert seulement :

- `.well-known/assetlinks.json` : lien entre le site et l'app Android KLOZIO (`games.squadranostra.klozio`), pour que l'app s'ouvre sans barre d'adresse ;
- `index.html` : redirection vers https://jldlab.github.io/klozio-site/.

`.nojekyll` : sans lui, GitHub Pages ignore le dossier `.well-known`.
